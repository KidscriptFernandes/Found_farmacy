# Found Farmacy

> Encontre farmácias e hospitais perto de você.

O **Found Farmacy** é uma aplicação web desenvolvida para facilitar a localização de farmácias e hospitais próximos ao utilizador.

O projeto tem como foco uma experiência simples, rápida e intuitiva, permitindo pesquisar estabelecimentos de saúde, consultar informações básicas e visualizar localizações.

## Funcionalidades

* Localização de farmácias
* Localização de hospitais
* Pesquisa de estabelecimentos
* Visualização no mapa
* Informações básicas dos estabelecimentos
* Conselhos gerais de saúde

## Tecnologias

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion

## Instalação

```bash
git clone https://github.com/KidscriptFernandes/Found_farmacy.git
cd Found_farmacy
npm install
npm run dev
```

## Objetivo

O Found Farmacy está sendo desenvolvido inicialmente como um MVP, com foco em localização de serviços de saúde. Futuramente, o projeto poderá incorporar novas funcionalidades.
